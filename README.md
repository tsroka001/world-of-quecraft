# World of Quecraft

A launch-day queue simulator. It's a parody of what logging in to a fantasy MMO feels like on launch day: you sit at the login screen while queues run into the tens of thousands, the patcher stalls at 99%, and you get disconnected at position 1.

There's no game behind it. The whole point is the login screen.

**Play it:** download `index.html` and open it in a browser.

## What's in it

- A storm-lit castle gate drawn live on a canvas, with a crowd of players waiting outside
- Realm queues with time estimates that jump around, realm restarts, and disconnects
- New realms that open during your visit and fill up within a minute
- A Launch News feed that keeps posting updates
- Small achievements for how long you've waited

Any account name and password work. Nothing you type leaves the page. Your total time and achievements are saved only in your own browser.

## Running it locally

It's a single `index.html` file with no build step. Open it in a browser, or serve the folder with any static file server.

Fonts load from Google Fonts. Everything else is in the one file.
